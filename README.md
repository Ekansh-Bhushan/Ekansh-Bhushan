
## ✨ About Me

Final-year Computer Science student building production-grade systems, not classroom demos.

Focused on scalable backend architecture, clean system design, and writing code that survives real traffic, real users, and real constraints.

Currently diving deep into Android development with Kotlin, emphasizing performance optimization, architecture patterns (MVVM, Clean Architecture), and maintainable codebases that scale beyond MVPs.

I care about engineering fundamentals — data structures, concurrency, databases, networking — and I apply them to build systems that are efficient, observable, and reliable.
